The Model

Quantitative risk from 3-point estimates

Construction projects are inherently uncertain — task durations depend on weather, labour availability, material delivery, and unforeseen site conditions. Deterministic CPM gives a single point estimate that is almost certainly wrong.

This engine replaces fixed durations with Beta-PERT probability distributions — each task is described by three estimates: optimistic, most likely, and pessimistic. Running CPM 10,000 times gives a full probability distribution of project completion.

"The PERT technique was developed for the Polaris missile program in 1957 and remains the standard for project schedule risk analysis." — Malcolm et al. (1959). Operations Research, 7(5).

The Cost Overrun VaR applies the same Value-at-Risk methodology used in financial risk management — giving the maximum probable overrun at a given confidence level.

// Beta-PERT distribution
μ = (O + 4·M + P) / 6
σ = (P - O) / 6
// O=Optimistic M=MostLikely P=Pessimistic

// CPM Forward Pass
ES[i] = max( EF[pred] for pred in predecessors )
EF[i] = ES[i] + duration[i]

// Total Float (0 = critical)
TF[i] = LS[i] - ES[i]

// Cost Overrun VaR
CostVaR95 = P95( simulated_cost ) - baseline

// Criticality Index
CI[i] = P( task i is on critical path )
Algorithms

Three-layer risk pipeline

01 —
Beta-PERT Sampling
Each task's duration and cost are sampled from a Beta-PERT distribution fit to 3-point estimates. The Beta distribution is bounded, skewed, and parameterized by the mode — ideal for engineering durations.
α = (μ-O)/R · [(μ-O)(P-μ)/σ²-1]
samples ~ Beta(α,β) scaled to [O,P]
02 —
CPM Schedule Propagation
For each set of sampled durations, a full CPM forward + backward pass computes Early/Late Start/Finish for every task. The critical path (zero float) is identified in each simulation.
EF[i] = ES[i] + d[i]
ES[i] = max(EF[pred])
TF[i] = LS[i] - ES[i]
03 —
Risk Metrics Aggregation
Across 10,000 simulations: P50/P80/P90/P95 completion dates, cost overrun VaR, criticality index per task, and Spearman correlation for sensitivity analysis (tornado chart).
CI[i] = #{critical in sim i} / N
ρ[i] = Spearman(d[i], Proj_Duration)

Codebase

5-module pipeline

[ DATA ]
Project Generator
project_generator.py
3 project templates (residential, commercial, infrastructure). 18–28 tasks with 3-point estimates and dependency graph.
[ SCHEDULE ]
Beta-PERT
pert.py
Beta distribution fitting, sampling, CDF, percentiles. Vectorized for MC efficiency.
[ SCHEDULE ]
CPM Engine
cpm.py
NetworkX DAG. Forward + backward pass. Float computation. Critical path extraction via longest-path algorithm.
[ RISK ]
Monte Carlo + VaR
monte_carlo.py · sensitivity.py
10k CPM runs. Criticality index. Cost VaR/CVaR. Spearman tornado chart. Fully reproducible.
[ UI ]
Dashboard
app.py
Streamlit: Gantt, distributions, criticality bars, sensitivity tornado, full risk register table.
45 unit tests · PERT mean/std formula · sample bounds · CDF monotonicity · CPM sequential chain = Σ durations · parallel paths = max branch · float = 0 on critical path · Monte Carlo P90 ≥ P50 ≥ P10 · criticality ∈ [0,1] · predecessor ordering validation · GitHub Actions CI (Python 3.10 & 3.11)
Usage

Running in 3 steps

01 — INSTALL

Setup

# Clone the repository
git clone https://github.com/
  alaaeddinethr/construction-risk
cd construction-risk

# Install dependencies
pip install -r requirements.txt

# Run test suite
pytest tests/ -v
02 — SIMULATE

Run analysis

# Generate project
python src/data/project_generator.py \
  --type residential \
  --output data/project.json

# Run CPM
python src/schedule/cpm.py

# Monte Carlo (10k sim)
python src/risk/monte_carlo.py \
  --simulations 10000
03 — DASHBOARD

Interactive view

# Launch Streamlit
streamlit run \
  src/dashboard/app.py

# Open browser
→ http://localhost:8501

# Choose project type,
# set simulations,
# click Run
